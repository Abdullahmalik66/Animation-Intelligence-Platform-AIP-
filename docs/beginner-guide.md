# Beginner Guide — Ask for Animations in Plain Language

You don't need to know anything about programming or animation libraries.

## How to ask
Describe **what you want people to see**, for example:

- "I want the cards to appear one at a time when someone scrolls down."
- "Make the button grow a little when the mouse is over it."
- "Add the loading animation our designer made."

## What happens next
1. The system reads your project to find out what tools are already there — you don't have to tell it.
2. It first asks itself: *does this even need animation?* Sometimes the honest answer is no.
3. It picks the simplest safe way to do it.
4. It checks accessibility automatically: people who turn on "reduce motion" in their device settings always get a calm version, and nothing important is shown only through movement.

## What you'll get back
```
What I understood
What will happen on screen
What the system chose
What was created or changed
How to test it
Accessibility and reduced-motion behaviour
Anything that still needs attention
```

## Important honesty rules
- If the system isn't sure what you meant, it will **say so and ask** — for example, "moves as I scroll" can mean two different things.
- If it can't verify which animation tools your project has, it will say the work is **not ready yet** instead of guessing.
- "Ready" is only shown when checks actually passed. Uncertainty is never hidden.

## Want more detail?
Ask for **guided mode** (a few simple questions, like "should this repeat?") or **expert mode** (full technical evidence). The same safety rules apply in every mode.
