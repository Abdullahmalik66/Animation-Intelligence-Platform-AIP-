# Eval Rubric: Animation Implementation Quality

Use this rubric to score any animation implementation generated by an AI agent.

---

## Scoring (Total: 100 points)

### Correctness (25 points)
- [ ] Animation achieves the intended visual effect (10)
- [ ] Sequence/timing is correct (5)
- [ ] Initial and final states are set correctly (5)
- [ ] No FOUC (flash of unstyled content) (5)

### Accessibility (25 points)
- [ ] `prefers-reduced-motion` handled (10)
- [ ] Static fallback for all animated content (5)
- [ ] No flash >3 times/second (5)
- [ ] Decorative animations aria-hidden (5)

### Performance (20 points)
- [ ] Only `transform` and `opacity` animated (10)
- [ ] No forced synchronous layout (5)
- [ ] Cleanup on unmount (5)

### Code Quality (15 points)
- [ ] No magic numbers (5)
- [ ] No TypeScript `any` (5)
- [ ] Named constants for durations/easing (5)

### Cleanup (10 points)
- [ ] Correct cleanup method for the library (10)
- Auto-fail if no cleanup present

### Security (5 points)
- [ ] No untrusted asset URLs (3)
- [ ] No secrets in config (2)

---

## Score Thresholds

| Score | Result |
|---|---|
| 90–100 | Exemplary — production ready |
| 75–89 | Good — minor improvements |
| 60–74 | Acceptable — notable issues |
| 40–59 | Poor — refactor recommended |
| <40 | Fail — do not ship |

## Auto-Fail Conditions

Any of these = automatic fail regardless of score:

- No `prefers-reduced-motion` handling
- No cleanup on unmount (memory leak)
- Layout properties animated (width, height, top, left)
- Assets loaded from untrusted external URL
